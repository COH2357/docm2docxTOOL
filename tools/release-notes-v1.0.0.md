## DOCM → DOCX 批量无损转换器 v1.0.0

把电脑上的 `.docm`(启用宏的 Word 文档)批量转成 `.docx`,**内容无损**,带图形界面、实时进度与自检闭环。

### 📦 下载

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `docm2docx-v1.0.0-portable.zip` | 29.5 MB | **便携版**:内含 Python + pywin32 + Everything,解压即用,**无需安装任何东西** |
| `docm2docx-v1.0.0-source.zip` | 0.1 MB | 纯源码,需自备 Python 3.8+ |

### 🚀 快速开始

1. 解压便携版到任意目录
2. 双击 `run.bat`(或先双击 `创建桌面快捷方式.bat` 生成桌面图标)
3. 界面里:选分区/文件夹/文件 → **开始扫描** → **开始转换**

### ✨ 本版亮点

**三档高速搜索内核** — Everything 索引 / Windows 搜索索引 / 直接遍历。
同一次扫描里,索引内核与遍历内核**结果完全一致**,但快一个数量级(实测 E 盘 1.3s vs 14s,冷缓存时 126s vs 1.3s)。
内核思路移植自 Flow Launcher 的 `Flow.Launcher.Plugin.Explorer/Search`。

**无损转换** — 走 Word 引擎另存,标题层级、样式、列表、表格、图片、形状、超链接、域、页眉页脚、脚注、分页、字符级格式全部保留;打开时强制禁用宏,原 `.docm` 只读不动。

**源文件处理** — 转换成功后可选「不处理 / 移到回收站(可恢复)/ 永久删除」。**只有转换成功的文件会被处理**,因同名 `.docx` 已存在而跳过、或转换失败的文件,源文件一律保留。

**13 项机器校验 + 人工复核** — 自动生成含 33 类元素(多级标题/列表/表格/图片/形状/超链接/域/页眉页脚/脚注/字符格式)的测试 `.docm`,逐项比对正文文本、结构计数、Word 层统计;还能在 Word 里并排打开两个文件人工核对。

**进程干净** — 后台 Word 实例用完即关,不残留 `WINWORD.EXE`(每个约 170MB)。

### ⚙️ 环境要求

- Windows + **Microsoft Word**(必需,2010 及以上)
- 便携版**不需要**预装 Python / pywin32 / Everything
- 想让内置的 Everything 拥有完整 NTFS 索引:以管理员身份运行一次 `runtime\everything\Everything.exe -install-service`

### ⚠️ 已知限制

- 转换速率受 Word 限制,约 20–60 个/分钟(大文档明显更慢)
- Windows 搜索索引内核只覆盖被索引的位置;Everything 内核覆盖全部已索引的 NTFS 卷
- 只处理 `.docm`,`.doc` / `.docx` 不在范围内
