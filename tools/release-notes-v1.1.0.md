### 🆕 本版新增:损坏文档自动修复

被宏病毒感染过的 `.docm` 经常“文件还在,但 Word 报文件已损坏”。根因通常不在正文,而在 OPC 包结构:关系 Id 重复、同名部件重复、关系指向不存在的部件。Word 手工“打开并修复”一般能救回来,但 COM 的 `OpenAndRepair=True` 对这种关系级损坏无效。

现在转换失败时会自动:

1. 先尝试 Word 自带的“打开并修复”;
2. 仍失败则修复 OPC 包结构:去重同名部件、修正重复关系 Id、删除完全重复/失效的关系、清理 `[Content_Types].xml`;
3. 交给 Word 重新另存为 `.docm`,同时**剔除 VBA 宏工程**;
4. 用修复后的 `.docm` **覆盖原文件**,再继续转 `.docx`;
5. 之后的“保留 / 移到回收站 / 永久删除”策略照常作用于修复后的 `.docm`。

安全与边界:

- 打开任何文档前仍强制禁用宏(`AutomationSecurity=ForceDisable`),不会执行病毒宏;
- 修复后的 `.docm` 已去掉宏工程,即使保留下来也不会再触发宏病毒;
- 修复产物校验不通过**不会**覆盖原文件;
- 原文件所在目录不可写时,改用临时副本继续转换,并提示“原文件未被覆盖”;
- 不想覆盖原文件时,取消 GUI 里的“转换失败时尝试修复损坏文档”,或命令行加 `--no-repair`。

### 🐞 本版修复

- **单文件扫描误触发全盘扫描**:只选单个文件时,空目录列表会被搜索内核理解为“全盘”,可能意外处理整机 `.docm`。现在没有目录目标时直接返回空,单文件只处理该文件。
- 修正 `DisplayAlerts` 常量值(Word 只接受 `0 / -2 / -1`),避免设置警告级别时报“参数超出范围”。

### 🚀 快速开始

1. 解压便携版到任意目录;
2. 双击 `run.bat`(或先双击 `创建桌面快捷方式.bat` 生成桌面图标);
3. 界面里:选分区/文件夹/文件 → **开始扫描** → **开始转换**。

### 🔄 升级说明

便携版直接解压覆盖旧目录即可;想保留旧版也可以解压到新目录。v1.0.0 的 `.docx` 输出和本版格式一致,不需要重新转换(除非想用新的修复功能处理之前失败的文件)。

### ⚠️ 已知限制

- 需要本机安装 Microsoft Word(2010 及以上);转换速率受 Word 限制,约 20–60 个/分钟,大文档明显更慢;
- 修复只针对 OPC 包结构损坏;如果正文部件本身已损坏,仍可能失败;
- 修复会覆盖原 `.docm`(去宏版),介意时请先备份,或关闭修复选项;
- 只处理 `.docm`,`.doc` / `.docx` 不在转换范围内。
